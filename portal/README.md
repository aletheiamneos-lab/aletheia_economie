# Pagina de start amentor.ro

Pagină statică cu alegerea materiei: Logică (logica.amentor.ro) și Economie (economie.amentor.ro).
Orice link vechi de tipul amentor.ro/ceva este redirecționat către logica.amentor.ro/ceva,
ca să nu se strice linkurile pe care elevii le au deja.

Publicată pe Vercel ca proiect separat (`amentor-portal`, Root Directory: `portal`).
