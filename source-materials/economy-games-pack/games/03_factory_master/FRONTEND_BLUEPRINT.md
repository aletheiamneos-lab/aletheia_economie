# FRONTEND BLUEPRINT — Factory Master
Main scene: isometric factory connected to live cost dashboard.

Interactive elements:
- worker count stepper;
- drag worker tokens onto line;
- machine upgrade control;
- production run button;
- target-production marker;
- CT/CV/CF chart;
- CMT/CMV/CMF/Cmg chart;
- profit/revenue panel;
- break-even marker;
- compare two configurations;
- replay production;
- restart.

Animation:
machines accelerate with output, idle workers wait visibly, cost bars grow, profit flips between loss/profit states.
