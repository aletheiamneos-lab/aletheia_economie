# FRONTEND BLUEPRINT — Economic Pulse
Main scene: business-cycle chart synchronized with a macroeconomic city.

Interactive elements:
- timeline scrubber;
- phase selector;
- indicator inspector;
- policy builder;
- run-next-quarter;
- counterfactual toggle;
- before/after comparison;
- chart annotations;
- explanation drawer;
- restart.

Animation:
construction, factory activity, traffic, shop activity and investment visuals respond to the detected cycle phase.
