# FRONTEND BLUEPRINT — Global Trader
Main scene: stylized world map with trade routes.

Interactive elements:
- select partner;
- drag product/container to route;
- route-thickness feedback;
- exports/imports controls;
- FX gauge;
- competitiveness meter;
- policy cards;
- shock banner;
- trade-balance dashboard;
- route diversification;
- compare partners;
- restart.

Animation:
ships/planes move along active routes; import/export direction is obvious; route volume changes thickness and speed.
